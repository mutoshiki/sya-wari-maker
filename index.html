3. メンバーカードの操作

カードには様々な機能があります。名前をタップすると属性が変わります。

男子
女子
1年男子
1年女子
名前をクリック： 男 → 女 → 1男 → 1女 の順に切り替わります。
メモ機能：住所や備考を入力できます。入力があるとアイコンがオレンジになります。
ロック機能：タップして鍵（）をかけると、自動割当や全解除で動かなくなります。確定した人に便利です。
削除ボタン：カード右上の「×」で削除します。
4. 車の設定
佐藤車 3/4

右上の数字（定員）をクリックすると、乗車人数を変更できます。
運転手名をタップで性別変更、アイコンで運転手メモも可能です。

5. 便利ツール
自動割当

実行すると、自動でメンバーを車に割り振ります。「設定」で学年や性別でまとめたりもできます。

LINE / URL

現在の結果をテキストでコピーしたり、この部屋のURLをグループに共有して、共同編集・閲覧出来ます。
